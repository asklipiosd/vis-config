# My vis config
Here is my vis config, it includes some "plugins" I have made on my own and I think add some value.

## My plugins
- **vis-tmux**: allows spawning tmux splits from vis, with vis running
- **bannerate**: vis bannerate port stolen from https://github.com/if-not-nil/dots (thanks lung)
- **execCmd**: set a command to run when pressing a key
- **CreateFile**: interactively creat and open a file
- **vis-typst-preview**: tinymist preview for typst, sort of kind of works

## plugins I use others have developed
- **vis-command**: open command in a split
- **vis-commentary**: comment with gcc
- **vis-autoclose**: autopairs
- **vis-colorizer**: color hex codes
- **vis-lspc**: lsp client plugin
- **vis-fzf-open**: open fzf for picking files and stuff, but I will probably stop using it
